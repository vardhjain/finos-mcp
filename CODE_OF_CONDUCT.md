# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work and not the person,
and do not harass anyone. This applies to issues, pull requests, discussions and any other
space where the project is represented.

## Reporting

If someone's behaviour falls short of this, contact the maintainer privately through
[GitHub](https://github.com/vardhjain). Reports are kept confidential. The maintainer will
review each one and respond with whatever action is appropriate, from a private note to
removal from the project's spaces.

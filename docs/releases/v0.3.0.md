# FINOS MCP v0.3.0

This release makes the three independent, read-only FINOS standards servers more reliable and easier to evaluate. All features continue to work without a paid model, API key, or database.

## What's new

- **Updated AI Governance Framework:** 24 published risks and 25 controls (including the draft skill/plugin supply-chain risk and integrity/governance controls), refreshed OWASP LLM Top 10 crosswalks, and the upstream YAML fix merged in FINOS PR #380.
- **Updated Common Domain Model:** CDM 7.7.0 primary JSON Schema (1,143 schemas) and CDM 6.30.0 legacy validation (1,066 schemas), with vendored sample documents and SHA-256 source provenance.
- **More useful AIGF search:** When questions explicitly ask for risks or controls, retrieval prefers the requested record kind. Search also recognizes standards codes (such as NIST SA-9) and a conservative set of risk paraphrases without paid inference.
- **Free workflow evaluations:** 16 repeatable, multi-step CDM and FDC3 scenarios (51 actual MCP tool/resource interactions), with pass rates recorded in the CI metrics.
- **Reliable live demo:** All five real demo calls run across three sequential, short-lived server processes, avoiding cumulative memory pressure. CI records the actual transcript.
- **Verified container runtime:** The production image now uses Python 3.14, with an isolated, read-only Docker build/smoke check. The Python packages still support Python 3.12 and newer.
- **Dependency maintenance:** Updated Ruff, Pydantic, bm25s, model2vec, NumPy, DeepEval, inline-snapshot, and types-jsonschema.

## Safety and maintenance

- Anthropic agent-in-the-loop evaluations are **manual opt-in only**, so routine pushes do not make paid API calls.
- Vendored upstream drift is reviewable in a pull request rather than silently changing bundled standards data.
- No write-capable MCP tools have been added. The servers retain rate limits, size caps, structured errors, audit logging and verifiable offline data.

## Install or upgrade

Once v0.3.0 is published to PyPI, install the server(s) needed:

```bash
uvx --python 3.12 finos-mcp-aigf
uvx --python 3.12 finos-mcp-cdm
uvx --python 3.12 finos-mcp-fdc3
```

For pinned applications, choose package versions `finos-mcp-aigf==0.3.0`, `finos-mcp-cdm==0.3.0` or `finos-mcp-fdc3==0.3.0`; each requires `finos-mcp-core>=0.3.0`. The container will be available under `ghcr.io/vardhjain/finos-mcp:v0.3.0` after the release-tag workflow completes.

The packages are independent community tools, **not affiliated with, endorsed by, or published by FINOS**.

# FINOS MCP v0.3.1

This maintenance release updates the FINOS Common Domain Model data and makes validation of Rune documents more precise. The three servers remain read-only and work offline after installation. No paid LLM or API key is required.

## What's changed

- **Official CDM 7.8.0:** The primary vendored JSON Schema now uses CDM 7.8.0 (1,143 schemas), along with 28 official Rune samples. All upstream files retain SHA-256 provenance.
- **Legacy CDM 6.30.0 preserved:** The 1,066 legacy schemas and 12 legacy samples remain available for same-vintage validation.
- **Safer Rune validation:** Fully qualified CDM type names must match the namespace and selected schema vintage. Incorrectly named nested `@type` values are reported as validation errors rather than silently removed. Bare type names are still accepted where supported.
- **Release reliability:** The GitHub Release workflow explicitly names the repository when launching Docker publishing; this fixes the failed dispatch after v0.3.0's successful Python publication. The Docker image itself passed its recovered v0.3.0 build and smoke tests.
- **Public-install verification:** A non-publishing GitHub Actions workflow can now confirm that all four published packages install cleanly from PyPI and all three servers initialize on Python 3.12 and 3.14. The v0.3.0 release passed those live checks.

AIGF and FDC3 retain their existing vendored standards data. All servers retain read-only tool enforcement, input limits, structured errors, and audit logs. Automatic paid agent/LLM evaluations remain disabled.

## Install or upgrade

After **v0.3.1 is published**, install or pin only the servers you need:

```bash
uvx --python 3.12 'finos-mcp-aigf==0.3.1'
uvx --python 3.12 'finos-mcp-cdm==0.3.1'
uvx --python 3.12 'finos-mcp-fdc3==0.3.1'
```

All three servers use `finos-mcp-core>=0.3.1`. Python 3.12 or later is required. The versioned container will be `ghcr.io/vardhjain/finos-mcp:v0.3.1` after the release workflow succeeds.

The packages are independent community tools, **not affiliated with, endorsed by, or published by FINOS**.

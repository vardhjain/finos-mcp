# FINOS MCP v0.3.2

FINOS MCP v0.3.2 is a packaging and release-readiness update for three
independent, read-only Model Context Protocol servers:

- **AIGF** — find FINOS AI Governance Framework risks, controls and crosswalks.
- **CDM** — explore the Common Domain Model and validate CDM JSON.
- **FDC3** — look up context schemas, intents and context validation rules.

The runtime tools and vendored standards content are unchanged from v0.3.1.
The servers continue to run locally over stdio and require no paid LLM
service or API key.

## What changed

- **PyPI package ownership metadata:** The AIGF, CDM and FDC3 distribution
  READMEs now include their respective `mcp-name` markers for potential
  official MCP Registry ownership verification. This fixes the omission in
  the immutable v0.3.1 PyPI descriptions.
- **Release packaging checks:** The non-publishing release preflight checks
  the exact ownership marker inside each server wheel's distribution
  metadata and each source archive's packaged README.
- **Version alignment:** All four distributable packages now use v0.3.2,
  and each server requires `finos-mcp-core>=0.3.2`. Workspace versions,
  the dependency lockfile and release artifacts remain synchronized.
- **Registry preparation:** Three official MCP Registry manifests are
  validated and version-aligned for future submission. **Passing
  validation does not mean any server is registered.** Publication will
  require separate approval and verification of the public PyPI
  descriptions.

`finos-mcp-core` is a shared dependency, not a fourth MCP server.

## Install or upgrade

Python 3.12 or later is required. Install or pin only the servers you need:

```bash
uvx --python 3.12 'finos-mcp-aigf==0.3.2'
uvx --python 3.12 'finos-mcp-cdm==0.3.2'
uvx --python 3.12 'finos-mcp-fdc3==0.3.2'
```

Every server enforces read-only tools, size limits, request rate limits,
structured errors and audit logging. Local execution works without
network access once the packages and any optional models are installed.

These are independent community packages, **not affiliated with, endorsed
by, or published by FINOS**.
